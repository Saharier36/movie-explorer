## 📖 Overview

**MovieExplorer** is an intuitive, responsive web application tailored for cinephiles and casual viewers to effortlessly browse, discover, and search through a rich catalog of television shows and movies. Built with a bold, Netflix-inspired dark aesthetic—featuring deep pitch-black backdrops, crisp typography, and striking red accenting—the application delivers a premier streaming-like feel directly in the browser. Powered by the public TVMaze REST API, MovieExplorer combines real-time data fetching, fast search filtering, and comprehensive title insights into an engaging, fluid user experience across any device.

---

## ✨ Features

- **🎬 Hero Landing Page**: Captivating cinematic welcome section showcasing featured highlights with quick navigation actions.
- **📺 Movie & Show Listing**: Browse a vast collection of popular series and movies populated with high-res cover posters and ratings.
- **⚡ Live Instant Search**: Real-time query matching to search titles on the fly without refreshing the page.
- **🎴 Movie Details Modal**: In-depth pop-up overlay featuring expandable plot synopses, genres, release dates, ratings, and network metadata.
- **📐 Responsive Dynamic Grid**: Seamless auto-fitting card layout that adapts cleanly to varying screen widths and resolutions.
- **📱 Mobile-to-Desktop Responsiveness**: Fully responsive design with touch-friendly controls optimized across smartphones, tablets, and desktops.

## 🚀 Getting Started

Follow these steps to set up and run MovieExplorer locally:

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (version 18.0 or higher recommended) and `npm` installed.

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Saharier36/movie-explorer.git
   cd movie-explorer
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **View the application:**  
   Open your browser and navigate to `http://localhost:5173` (or the port specified in your console).
